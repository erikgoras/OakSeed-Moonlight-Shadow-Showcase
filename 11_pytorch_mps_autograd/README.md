# Lab 11 – PyTorch Device Selection, Cosine Similarity & Autograd

A compact, test-driven PyTorch demonstration covering Apple Silicon (`mps`) device selection, normalized pairwise cosine similarity, leaf-tensor autograd gradients, and input validation.

## Contents

- `torch_demo.py`: `get_device()`, `pairwise_cosine_similarity()`, `compute_scalar_gradient()`, and `TinyProjection`.
- `main.py`: Verification tests for device handling, tensor shapes, cosine similarity, autograd gradients, and error cases.
