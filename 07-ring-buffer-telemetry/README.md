# 07-ring-buffer-telemetry

Deterministic C++17 fixed-capacity ring buffer (`RingBuffer<T, Capacity>`) tracking ordered telemetry values, min/max, average, and push/overwrite counts over 15 samples in a capacity-8 buffer.

- **Max:** `150.15`
- **Avg:** `115.31`
- **Overwritten:** `7`
