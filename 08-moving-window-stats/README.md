# 08-moving-window-stats

Deterministic C++17 sliding-window statistics module (`SlidingWindowStats<T, WindowSize>`) computing ordered window values, min, max, mean, and population variance over 12 samples with a window size of 5.

## Final Summary Statistics
- **Size:** `5` / `5`
- **Min:** `1.10`
- **Max:** `8.90`
- **Mean:** `5.10`
- **Variance:** `7.28`
