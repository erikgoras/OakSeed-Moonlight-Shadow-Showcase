# 04 — Lunar Lander Descent Simulation (C++17)

## Task Specification
Self-contained C++17 program simulating an Apollo 11 style fixed-timestep lunar descent and touchdown evaluation without std::vector, std::array, or smart pointers. Uses constexpr constants for lunar gravity and pi, input validation, and test cases covering controlled descent, tight fuel margin, and invalid input handling.

## Build & Run
g++ -std=c++17 -O3 -Wall -Wextra lunar_lander.cpp -o app && ./app
